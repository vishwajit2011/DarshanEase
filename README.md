🛕 DarshanEase

DarshanEase is a digital temple platform that makes it easier for devotees to explore temples, check darshan details, book darshan, and make online donations from one place.

✨ Features
🛕 Temple & Darshan Information
🎟️ Darshan Booking
💰 Online Donations
👤 User Authentication
🔐 Secure & Responsive UI
⚙️ Admin Management
🛠️ Tech Stack

React.js • Node.js • Express.js • MongoDB • JWT

🚀 Run Locally
cd client
npm install
npm run dev
cd server
npm install
npm run dev

Version: v1.0.0
